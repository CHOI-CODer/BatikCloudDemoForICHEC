# BatikCloudDemoForICHEC

蜡染 AI 创作工坊。源码仓库：[CHOI-CODer/BatikCloudDemoForICHEC](https://github.com/CHOI-CODer/BatikCloudDemoForICHEC)。

在浏览器本地运行的蜡染创作前端。按产品文档 §15–§16 更新为 `0.2.9-preview`，DSL 1.3、渲染器 2.0.2。静态托管、零构建，印染核心无第三方运行依赖，图片默认保留在本机。

## 上传到网站使用

GitHub Pages 可选择 `main` 分支、`/ (root)` 目录直接发布，无需构建；仓库根目录已有入口和 `.nojekyll`。也可按以下方法部署到其他静态服务器。

1. 解压 `release/BatiScript-static.zip`。
2. 把解压后的**全部内容**上传到静态网站目录，保持 `index.html`、`web/`、`shared/`、`engine/` 的相对结构。不要只上传 HTML。
3. 访问网站根地址，自动进入工坊；单图入口为 `engine/batik_compiler.html`。支持部署在网站子目录。
4. 每个新窗口从空白工程开始。上传 PNG/JPG/WebP 或选择示例，调整效果后导出 PNG；代码菜单可保存完整项目。

左侧使用你指定的扣子官方 JavaScript Web SDK，已按负责人确认内置公开演示令牌，打开或刷新即自动连接，无需另外输入。配置和配方应用方法见 [Web SDK 使用说明](docs/ai-integration.md)。每个访客和窗口使用独立工坊工程。

本地开发可运行 `node tests/server.cjs`，访问 `http://127.0.0.1:4173`；Node 用于本地开发预览。网页访客无需安装任何软件。通过 HTTP/HTTPS 使用，直接双击 HTML 不是主验收路径。

## 本轮功能

- 上传后默认校正光影并输出纯黑白图，提供强度、阴影、高光调整，原图／统一后／印染后三态比较及本组重置；保留原始素材和透明度。
- 多色直接生成染色底色：随机分区、交叉混合，最多 8 色；每色比例、随机度和独立种子，比例条、重排分布、随机配色、每色换随机值。
- 冰纹密度与粗细、蜡滴、笔触、晕染和布纹恢复第一版的柔和强度，保留原数值单位。
- 最多 3 图层，独立选择、拖动、缩放、旋转、复制、删除、拖动排序及显示隐藏。十种图层叠加与原叠印／拼接／螺旋／交织分别设置。
- 浸染、冰裂蔓延、图案融合过程动画；时长、速度、播放暂停、继续、时间轴、循环和截帧。图案融合需要两层可见图案。
- Ctrl/Command+Z 撤销，Ctrl/Command+Shift+Z 重做；代码框撤销文本，非输入区域撤销作品。历史最多 50 个成功版本。
- “整理当前草稿”保留注释、字符串、未知内容与执行顺序，不直接应用画布；“查看成功代码”单独生成实际成功配方。
- 桌面左、中、右栏可拖动调宽；分隔条支持方向键、Shift 加速、Home 或双击恢复默认，保存布局偏好。手机使用堆叠编辑区及参数抽屉。
- 当前窗口刷新恢复自己的素材、配置、历史与草稿；“本机项目”显式打开独立副本；旧版自动保存不会自动加载到新访客。
- PNG 按目标尺寸重新渲染，最高 2048；UTF-8 `.batik`；含素材、历史与草稿的 `.batik-project.json`。
- Web SDK 使用负责人确认公开的演示凭据自动初始化，支持临时切换连接；生成代码通过粘贴面板应用。

## 创作要点

代码编辑器默认“完整快照”：主动删掉的效果回默认，写坏的属性保留有效旧值。“局部修改”和面板只改变明确指定的项。停止输入 400ms 自动应用，中文输入法组词期间暂停；Ctrl/Command+S 可立即应用。未应用草稿不会被面板覆盖。

光影统一处理可辨识的曝光和柔和阴影；原图已丢失的过曝、死黑或硬阴影细节需要更换照片。多色的比例是基础可染区域的面积或染料贡献，右侧统计在纹理、裁切和图层合成之前计算，不能按最终 RGB 像素直接计数。

每色随机度为 0 时，“换随机值”不会增加色差；先提高随机度。布局种子控制分区，纹理种子控制蜡染肌理，显式颜色种子控制该色变化；播放与导出沿用已保存种子。

代码只包含素材引用。跨设备请保存完整项目；仅导入 `.batik` 缺图时在素材关联中重新关联。自动保存限当前浏览器，重要作品请下载项目文件。旧作品按旧渲染器保留；通过“升级为新版印染”预览后确认转换，可撤销。详见 [迁移说明](docs/migration.md)。

本包为可部署预览版。已验证内置 Chromium 桌面与 390px 窄屏模拟；Safari、Edge 和手机真机仍待补充。实测范围与性能见 [本轮验收](docs/acceptance-0.2.0.md)，原版记录见 [历史验收](docs/acceptance.md)。

## 维护

`shared/registry.js` 是参数、颜色和别名的唯一来源；两个入口共用 parser、formatter、renderer、storage 和 AI 适配器。`renderer-legacy.js` 保存旧效果路径；`web/workshop-controls.js` 为本轮可视化控件。不要漏传新增脚本。

- 解析回归：`node --test tests/parser.test.cjs tests/upgrade.test.cjs`。
- 浏览器：启动本地服务后打开 `tests/browser.html` 和 `tests/upgrade-browser.html`。使用专用测试数据库，不影响普通工坊。
- 打包：`node tests/package.cjs`；校验：`node tests/verify-package.cjs`。`tests/` 不进入部署包。
