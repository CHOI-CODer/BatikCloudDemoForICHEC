# 0.2.8-preview · 预览与工具区高度分隔杆

作品预览和下方语法手册、当前代码、历史版本之间增加横向分隔杆。上下拖动可调整两部分高度，比例保存在本机布局偏好中。分隔杆具有焦点和 separator 语义，可用上下方向键微调，按住 Shift 每次调整 50px，Home 或双击恢复默认比例。

## 实际核对

- 工坊 1280×720 中，默认预览高 366px。向上拖 100px 后为 266px，按向下方向键后为 276px。
- 拖至上限时预览最小高 200px；向下拖至边界时，下方工具区最小高 240px。画布随预览尺寸等比适配，代码工具可滚动。
- Home 和双击均恢复预览高 366px。调至 316px 后刷新，恢复为 316px，作品代码相同。
- 拖动前后的作品代码相同；语法手册和历史版本可正常切换。
- 390×844 窄屏模拟中，分隔杆高 20px。通过鼠标指针向上拖动 60px，预览从 356px 调至 296px，页面宽保持 390px。
- 单图入口使用同一分隔杆，向下方向键调整 10px 成功。

记录见 tests/row-splitter-browser-report.json，截图见 docs/evidence-0.2.8/preview-splitter.jpg。触摸路径使用 Pointer Events；本机浏览器不支持合成触摸事件，触摸真机待验证。截图中的扣子登录界面是 SDK 的未登录状态。

本轮通过 JavaScript 语法、静态包解压、文件哈希、入口引用和凭据格式检查。核心解析、渲染、格式化与存储源码沿用保留的基线。未新增自动布局测试。旧版部署包保存在 BatiScript-static-0.2.7-preview.zip。
