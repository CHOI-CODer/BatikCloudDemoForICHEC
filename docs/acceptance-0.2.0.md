## 实际性能

以下为本机一次验收采样，包含本轮分块调度；不作为所有设备保证。

| 测量 | 结果 |
|---|---|
| 单图 768 冷预览 | 145 ms |
| 三图层多色＋正片叠底，768 冷预览 | 612 ms |
| 512 / 1024 / 2048 单图多色渲染 | 109 / 276 / 721 ms |
| 三图层画到显示画布的 rAF 采样 | 浸染 60.2 / 冰裂 60 / 融合 60.1 fps；各 25 帧短采样 |
| 界面实际导出 PNG | 2048×2048，4,008,014 字节；`release/example-0.2.0-2048.png` |

单图目标 300ms 在此次采样达到；高负载候选超过 300ms 时后续预览可降到 512，最终导出按指定分辨率重算。15 秒计算预算、任务取消和旧 job 隔离继续有效。帧率为短时本机观察，不代替各浏览器长期动画/内存压力测试。
