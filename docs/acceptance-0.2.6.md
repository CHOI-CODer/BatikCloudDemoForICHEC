## 本轮实测

- 分享地址 HTTP 200，响应头允许 iframe 嵌入。在项目部署页面，观察到 Web SDK 部署成功、公开可见及 2026-12-13 13:45 的链接失效时间。
- 已登录 Edge 独立打开链接后显示“代码生成智能体”与 sdk.coze.site 聊天框。未登录的内置浏览器会跳转扣子主页与登录引导。
- 本机工坊 1280×720 中，iframe 约 375×287，编辑器仍可用。点击重新加载后，作品代码保持一致。
- 使用粘贴面板预览“白底蓝花、冰裂纹密度 10”，成功应用到花鸟纹示例。
- 390×844 窄屏模拟中，页面宽为 390，iframe 约 366×329，编辑器高 205，无横向溢出。
- 单图入口的 iframe 使用相同分享地址。两个 HTML 入口加载本地脚本时均通过静态引用校验。
- JavaScript 语法检查通过。核心渲染、解析、格式化和存储源码与已保留的基线逐文件核对哈希，静态包检查内容与凭据格式。

观察记录见 tests/websdk-browser-report.json，真实截图见 docs/evidence-0.2.6/websdk-workshop.jpg。未登录环境中的嵌入页面可能显示空白或登录引导，图中据实保留。桌面浏览器登录态受用户操作影响，嵌入式完整对话尚未验证。当前包的交付状态为“嵌入与本地交互通过”，在线免登录聊天仍受扣子侧访问条件限制。
