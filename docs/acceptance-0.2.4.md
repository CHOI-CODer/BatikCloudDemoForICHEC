# 0.2.4-preview · 中栏预览铺满

预览区铺满中栏的可用宽高，空白上传面板覆盖整个区域。作品根据预览区较短的一边等比放大，完整显示正方形画面。调整窗口、分栏或打开动画栏时，预览尺寸实时变化。

## 实际核对

- 内置 Chromium 在 1600×900 的浏览器视口中，预览区约 904×720 CSS 像素，花鸟纹示例约 720×720。右栏加宽后，预览画布等比缩至约 614×614；拖动左栏也即时改变画布尺寸。两次分栏调整前后，作品代码相同。
- 拖动作品后，图层位置写入代码。撤销恢复原位置。开启浸染后，预览缩至约 661×661，给动画栏腾出空间。在 1280×720 视口操作 1024×1024 PNG 导出，应用显示下载成功。
- 390×844 窄屏模拟中，预览画布宽 390，页面无横向溢出，创作设置抽屉仍可打开。
- 1280×720 的单图入口使用同一布局。空白上传面板铺满预览区，载入示例后画布约 540×540，显示 1 / 1 图层。
- `node --test tests/parser.test.cjs tests/upgrade.test.cjs` 通过 55 项。静态包校验文件哈希与两个入口引用。

浏览器测量和交互记录见 tests/stage-browser-report.json。桌面截图见 docs/evidence-0.2.4/full-stage-desktop.jpg。手机为浏览器模拟。
