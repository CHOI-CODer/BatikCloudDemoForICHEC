# 旧代码与工程迁移 · 0.2.0-preview

新工程使用 schema 2、parser 1.1.0、renderer 2.0.0、DSL 1.3；工坊与单图入口共用语义，分别保存工作区。

## 0.1.0 工程

- schema 1 或 renderer 1.x 的项目校验后保持 renderer 1.0.0，缺少光影配置时默认关闭，多色默认关闭，图层叠加正常、显示开启。原融合与旧套色按 `renderer-legacy.js` 重算。
- 缺少动画时长的旧工程补入 2.4 秒；有效时长仍为 `12/速度` 秒。新项目为 6 秒，速度 5 时标准播放。
- 原 IndexedDB 的 `project/current` 和 `assets` 保留原件。“本机项目 → 旧版自动保存工程”显式打开为当前窗口副本，新访客不会默认打开它。
- 原有新式工程和素材进入 `workspaces`、`workspaceAssets`，按工作区标识保存。当前窗口刷新保留自己的标识；复制标签检测到活跃同标识时生成新工程。打开其他项目会创建当前窗口副本，不覆盖来源窗口。
- “升级为新版印染”先预览再确认。旧套色强度不能换算面积；转换预览给主色 50%，其余 50% 在旧套色颜色间均分，最多保留 8 色。用户应在确认前核对并随后调整比例。旧强度不当作比例使用。升级进入一次历史，可撤销到旧外观。
- 旧项目中的新控件操作会先打开升级预览。显式导入/应用含新 DSL 指令的代码属于采用新版效果的操作；建议先保存旧项目。

## 代码与数值

L1 裸数密度 `1.2` 直接使用；L2 冰裂纹密度 `60` 除以 50。显式 `60%` 均为内部 1.2。L2 浸染深度 `80` 为 0.8，透明度 `70` 为 0.7；不按大小猜单位。新光影、配色比例、随机度与混合度的裸数 80 与 80% 均为 0.8。

用户原六项数值保持映射：10→0.2、1.25→1.25、72.5→1.45、90→1.8、80→1.6、80→1.6。新版改变肌理响应，未改变这些单位。

旧 `套色` 代码和 renderer 1.x 标记继续走旧兼容路径。新界面及新配方生成 `多色印染`、`配色n`，底色在纹理之前生成。无版本代码仍按登记的 L1/L2 映射解析；未取得的其他历史解释器不能承诺逐像素一致，保留原效果图对照。

完整快照省略效果回默认；无效属性保留有效值；patch 省略保持。新配色编号稳定，修改比例后其他颜色联动，删除不重编号，全零组回退。图层显示和颜色叠加与原空间融合分开保存。

`.batik` 只有素材引用；完整备份用 `.batik-project.json`。项目包含原素材 Blob 数据、配置、版本、种子、成功代码、原文与历史；不保存临时对象 URL。未知 schema 拒绝导入并保留当前作品。
