# Web SDK 页面嵌入

应用 0.2.7-preview 在工坊和单图入口的左栏嵌入用户提供的页面。语法手册、当前代码和历史版本位于作品预览下方。

https://code.coze.cn/web-sdk/7707450410642096179

## 部署与使用

解压 BatiScript-static.zip，把全部文件上传到静态网站目录，保持 web、shared、engine 等相对路径。用 HTTP/HTTPS 访问入口。页面直接加载扣子提供的分享页面。

左上角提供重新加载、独立打开、复制当前配方和粘贴代码。把智能体回复中的 batik 代码复制后，点“粘贴代码”，预览修正并应用。需要让智能体参考当前作品时，可用“复制当前配方”将成功代码复制给它。

iframe 与工坊分别处理各自的内容，回复通过手动复制粘贴进入本地解释器。Web SDK 的聊天记录、登录状态和会话隔离由扣子页面处理。工坊继续使用原有独立工程存储。

## 当前链接的访问条件

2026-11-13 实际查看项目部署页，Web SDK 已部署并公开可见，链接有效期为 30 天，后台显示于 2026-12-13 13:45 失效。

已登录的 Edge 打开分享链接后，能够显示“代码生成智能体”及 sdk.coze.site 的聊天界面。未登录的内置浏览器打开相同地址，会跳转到扣子主页与登录引导。当前验证覆盖嵌入和代码应用，尚未确认未登录访客能直接对话。

若左上角为空白或显示登录页面，可点“独立打开”，在扣子完成登录后重新加载。实际访问仍受扣子的分享有效期、项目权限和浏览器登录策略影响。长期部署需在扣子后台管理该分享链接有效期。

## 与 0.2.5 的关系

当前入口使用 Web SDK 分享页面。旧的 API 连接源码保留在工作目录中，0.2.5 的完整部署包另存 release/BatiScript-static-0.2.5-preview.zip。0.2.6 部署清单提供静态页面和 Web SDK 嵌入所需文件。
