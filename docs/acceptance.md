## 性能与限制

固定内置 1024px 数字花鸟纹，种子 2026，单图 768px 的一次冷预览实测约 157ms；单图冰裂蔓延的 25 帧 rAF 采样约 60fps。最终运行数值记录在 JSON 中，可能随前台状态和机器负载变化；不外推到所有设备或三图层。预览可在慢任务后降到 512，导出仍从成功配置与源图按目标尺寸计算。Worker 未使用，采用按行分块与取消检查路径。

未实测：Safari/Edge、iOS Safari/Android Chrome 真机、实际中文 IME 的系统候选窗（本轮验证合成事件契约）、首次断网加载、跨浏览器逐像素一致、真实 AI/CORS/鉴权。断开 AI 是默认状态，不承诺首次访问离线站点。GIF/视频与账号/云同步不属于本阶段。

这是可静态部署的前端预览移交，不创建正式发布标签；跨浏览器/真机补测与负责人 P5 联调仍需继续。
