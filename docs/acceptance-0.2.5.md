# 0.2.5-preview · 扣子智能体

2026-11-13 按用户提供的接口接入指定蜡染智能体，左上角显示连接状态、流式文字及代码建议，提供新对话、取消、重试和代码应用入口。两个前端入口共享适配器。

## 接口实测

提供的凭据在内存中使用，接口返回 HTTP 200 和 text/event-stream，收到 message_start、answer 和成功 message_end。跨域 OPTIONS 返回 401，采用同源 Node 连接服务调用。项目编号按原始 19 位整数发出。部署包内含服务与配置说明，服务器需配置 BATIK_COZE_TOKEN。

## 浏览器实测

- 花鸟纹示例请求白底蓝花、冰裂纹密度 10。真实智能体返回对应 batik 代码。回复显示期间作品代码保留，预览后应用成功。
- 第二条真实请求取消后，原作品保留，并出现重试按钮。重试期间手动修改蓝白取向，回复显示“基于旧版本生成，仅作为建议”。
- 暖棕色回复含无效颜色与超范围套色强度，预览显示部分应用及四条修正/跳过记录。局部容错按原有管线执行。
- 新对话清理页面消息并提示开始新对话。会话 ID 的连续复用、页面独立及新对话更新经单元测试验证。
- 单图入口检测连接成功。390×844 窄屏模拟的页面与画布宽均为 390，聊天区域与代码编辑器可见。
- 无凭据对照服务显示待配置，仍可载入示例、切换白底蓝花，PNG 导出入口可用。

记录见 tests/agent-browser-report.json，截图见 docs/evidence-0.2.5/coze-workshop.jpg。窄屏使用内置 Chromium 模拟。
